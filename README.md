# COFI EPLE

Application autonome de préparation des comptes financiers EPLE. Version 0.1.0 : dossier COFI 2025, checklist documentaire versionnée, import PDF, import EBLC N/N-1 et audit.

## Périmètre 0.1.0
- portefeuille de dossiers COFI ;
- `COFI_SCHEMA_2025` configurable ;
- conditions documentaires ;
- import PDF avec SHA-256 et remplacement historisé ;
- import EBLC CSV N/N-1 ;
- journal d'audit ;
- cockpit par établissement.

Hors périmètre : YECBUD/YECBUR, YFDR, analyse financière, rédaction de l'annexe, reconnaissance automatique des PDF et fusion finale.
